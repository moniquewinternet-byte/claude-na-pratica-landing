# Site Monique

Site estático pronto para publicação no GitHub e no Netlify.

## Estrutura

- `index.html`: página principal
- `assets/head.png`: foto do topo
- `assets/apresentacao.png`: foto da apresentação pessoal

## Publicação no Netlify

No Netlify, importe este repositório pelo GitHub. Como o projeto é um site
estático, não é necessário informar comando de construção. Use a raiz do
repositório como diretório de publicação.
